Frequently asked questions

How do I create a request?

Select New request, complete the required details, then choose Create request.

How do I change a request’s status or assignee?

Open the request’s action menu, select Edit request, update its status or assignee, and save your changes.

Can I restore a deleted request?

Yes. Deleting a request moves it to Archives. Open Archives and select Restore request to put it back on the request board.

Where are my requests and settings stored?

Requests and archived items are stored by the FlowDesk server and reset when its in-memory store restarts. Your default request status is saved in this browser.
